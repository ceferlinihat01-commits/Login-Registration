# Login & Registration Website

A responsive Login and Registration website built using HTML and CSS.

## About the Project

This project includes two connected pages: Login and Registration. I created it to practice HTML forms and CSS styling.

## Technologies Used

- HTML5
- CSS3

## Features

- Login and Registration pages
- Email and password input fields
- Form validation using required attributes
- Responsive design
- Hover and focus effects
- Navigation between Login and Registration pages
